<h1>LivUp Filter</h1>
<p>This is my first Tampermonkey script created to solve a really simple problem: filter lunch boxes on LivUp website for nutritional purposes. Since I had fun during the process, I considered it would be good to publish it here. I hope it can helps someone (:</p>
<h3>Installation Instructions</h3>
<p>
The installation process is the same for install any script on Tampermonkey so I get this instructions from the BlueMarble repository. Hope u dont mind.
<br><br>
Click the arrows to expand the instructions you want to see. Blue text is a link.
<details>
    <summary>
    <b>Install Chrome</b> <sup>(Click to expand)</sup>
    </summary>
    <ol>

    <img alt="Enter the 'Manage Extension' menu" src="https://github.com/SwingTheVine/Wplace-BlueMarble/blob/main/docs/assets/ComputerChromeInstall2.png"></li>
    <li>Left-click "Manage Extension."</li>
    <li>Enable "Developer Mode."
    <br>
    <img alt="Enable 'Developer Mode' and 'Allow user scripts'" src="https://github.com/SwingTheVine/Wplace-BlueMarble/blob/main/docs/assets/ComputerChromeInstall3.png"></li>
